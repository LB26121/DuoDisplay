# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): be welcoming, respectful and constructive. Harassment, insults, personal attacks and doxxing are not tolerated anywhere in the project.

Report unacceptable behaviour privately to the maintainer (contact on their GitHub profile). Reports are confidential. Maintainers may remove comments, close threads or block violators.
